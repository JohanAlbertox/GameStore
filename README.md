\# GameStore - E-commerce (PHP + MySQL)



\## Como rodar

1\. Copie .env.example para .env e ajuste as credenciais do MySQL.

2\. Importe database/schema.sql no phpMyAdmin.

3\. Na pasta do projeto: php -S localhost:8080

4\. Acesse http://localhost:8080
